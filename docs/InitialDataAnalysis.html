1.1 Distribution plot

Code 
p1 <- df %>% 
  filter(!is.na(addicted)) %>% 
  mutate(
    social_hours = factor(social_hours, levels = c("1-2","3-4","4-5","5-6","6+"))
  ) %>% 
  count(social_hours, addicted) %>% 
  group_by(social_hours) %>% 
  mutate(pct = n / sum(n)) %>% 
  ggplot(aes(x = social_hours, y = pct, fill = addicted)) +
  geom_col(position = "fill") +
  scale_y_continuous(labels = percent_format()) +
  scale_fill_manual(values = c("yes" = "#E07070", "no" = "#70B8E0", "not sure" = "#C0C0C0")) +
  labs(
    title = "Addiction by Daily Screen Time",
    x = "Hours/day on social media",
    y = "Proportion",
    fill = "Addicted?"
  ) +
  theme_minimal()

p2 <- df %>% 
  ggplot(aes(x = age)) +
  geom_histogram(binwidth = 2, fill = "#4C9BE8", colour = "white") +
  labs(title = "Age Distribution of Respondents", x = "Age (years)", y = "Count") +
  theme_minimal()

p2 + p1

Interpretation: The left histogram reveals that the respondents’ ages are heavily concentrated between 18 and 26 years, reflecting a predominantly student-based demographic. The right proportion bar chart demonstrates a clear dependency trend: while users spending 1–3 hours daily mostly report not feeling addicted, the proportion of self-reported addiction (“Yes”) expands rapidly as daily screen time exceeds 4 hours.

Interpretation: This grouped bar chart compares the self-reported influence of social media advertising on purchasing behavior across genders. The distributions are remarkably similar, with both males and females most frequently reporting an “often” or “sometimes” influence on their consumer choices. This suggests that gender alone does not explain differences in susceptibility to digital marketing within this sample.

p2_interaktiv <- df %>% 
  filter(!is.na(social_hours), !is.na(family_hours)) %>% 
  mutate(
    social_hours = factor(social_hours, levels = c("1-2", "3-4", "4-5", "5-6", "6+")),
    family_hours = factor(family_hours, levels = c("1-2", "3-4", "4-5", "5-6", "6+"))
  ) %>% 
  count(social_hours, family_hours) %>% 
  group_by(social_hours) %>% 
  mutate(percent = n / sum(n) * 100) %>% 
  ggplot(aes(x = social_hours, y = percent, fill = family_hours, 
             text = paste0("Family Time: ", family_hours, "<br>",
                           "Anteil: ", round(percent, 1), " %"))) +
  geom_col() +
  labs(
    title = "Social Media Hours vs. Family Time",
    x = "Daily social media hours",
    y = "Proportion (%)",
    fill = "Family hours/day"
  ) +
  theme_minimal()

ggplotly(p2_interaktiv, tooltip = "text")

Interpretation: This interactive proportion chart examines whether high screen time displaces offline family interaction. Contrary to the assumption of a strict negative correlation, the distribution of family time remains surprisingly stable across different social media usage brackets. This indicates that screen time alone does not directly cannibalize family hours, suggesting that factors such as academic workload or living arrangements may act as stronger confounders.

Beyond 6 hours daily, self-reported addiction becomes the overwhelming majority, visually validating our predictive modeling hypothesis.

1.2 Data quality

  • Intervals, not continuous values: all time variables (social_hours, family_hours, prof_hours) are in the form of strings (for example, “3-4”).
  • 78% of respondents are students, which limits generalisability to employed populations
  • One row has profession = "male" recoded to NA.
  • The response options are Yes / No / Not sure. The “Not sure” group (n = 125, 24%) is substantial and will be excluded from binary logistic regression, reducing the effective sample.

## Data quality
- Intervals, not continuous values: all time variables (`social_hours`,
  `family_hours`, `prof_hours`) are in the form of strings (for example,
  `“3-4”`).
- 78% of respondents are students, which limits generalisability to
  employed populations
- One row has `profession = "male"` recoded to `NA`.
- The response options are Yes / No / Not sure. The "Not sure" group
  (`n = 125`, 24%) is substantial and will be excluded from binary
  logistic regression, reducing the effective sample.
